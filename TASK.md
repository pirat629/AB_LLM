## ИИ агент для проведения A/B тестов

Агент должен по запросу генерировать SQL запрос, строить графики, проверять данные на выбросы, высчитывать метрики, выборирать тест, анализировать данные, проводить A/B тест, формулировать результат. Должен иметь доступ к внешним данные (базы данных, документы, информация о расходах и доходах для расчета unit экономики). Добавить возможность предиктивной аналитики, что бы модель могла предсказывать метрики.

На данный момент реализовано 5 скиллов:
* **generate_basic_sql** - Генерирует SQL запрос по запросу и ddl схеме бд. Генерируется промпт и передается модели, которая сама генерирует SQL запрос
* **profile_metric** - Получает на вход списки данных, а на выходе получается словарь с описанием этих данных (бинарность, наличие выбросов, размеры списков, средние значения, дисперсии)
* **select_stat_criterion** - Выбирает стат критерий в зависимости от профиля метрики. Сейчас реализован выбор из трех критериев (z тест для пропорций, Мана Уитни, t тест Уэлча)
* **calculate_ab_test** - Принимает на вход данные, стат критерий и параметр альфа. Проводит стат тест по полученным данным и выводи словать с результатами теста (Показатель стат критерия, p-value, альфа, стат значимость, относительный прирост)
* **interpret_results** - Формулирует итоговые рекомендации. На вход получает данные из A/B теста, генерирует промпт и передает в модель, которая по нему генерирует рекомендации.

Так же реализована система голден запросов и по 3 теста для каждого скилла.
